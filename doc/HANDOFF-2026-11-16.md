## Real bugs the tests caught and fixed (worth knowing)

1. Owner `/commands` were mutating the owner's own conversation row instead of the
   recipient's — caught by AC tests, fixed: owner commands now target the recipient.
2. The mock transport echoed outbound messages with the same `wa_message_id` the caller
   persists — UNIQUE index silently dropped real rows. Fixed (echo rows are id-less).
3. "Unanswered opener" guard was blocking the *first ever* check-in (consent confirmation
   counted as an outstanding opener). Fixed: only check-ins create that guard.
4. Emergency fast-path missed natural phrasing "মরতে ইচ্ছা করছে" — added several more
   distress phrasings to the keyword list.
5. Emergencies during owner-pause now fully escalate (interrupt the pause); during
   takeover/escalated they alert again but never resume autonomy.
